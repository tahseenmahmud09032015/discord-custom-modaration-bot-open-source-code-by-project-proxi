### **🌍 About**
**PROXI MOD BOT** is a fully **open source moderation bot for Discord**.
The goal: Give server owners complete control with clean, fast, and free moderation tools.

No premium tiers. No locked features. Just copy the code and run it.

> **"Open Source. Self Hosted. Community Driven."**

### **📜 Available Commands**
| Command | Description | Permission Needed |
| --- | --- | --- |
| `/timeout @user 10 reason` | Timeout a member | Moderate Members |
| `/kick @user reason` | Kick a member | Kick Members |
| `/warn @user reason` | Warn user + DM them | Moderate Members |
| `/warnings @user` | Check warning history | Moderate Members |
